# Documentation examples that cannot run unattended.
#
# ./test_doc_examples.sh runs every example, because running them is the only
# thing that executes most of the standard library. These cannot: they read a
# file the reader is expected to have, talk to a server, draw on a terminal,
# wait for a keystroke, or end the program on purpose.
#
# The list is checked both ways. An example here that starts passing is
# reported, so the line can be deleted. Nothing is skipped quietly, and
# nothing stays here because it was forgotten.
#
# Shrinking it is real work: an example that writes the file it then reads is
# a better example, because it is one a reader can paste and run.
